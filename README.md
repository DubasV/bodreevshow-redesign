# BodreevShow — демонстрационный редизайн

Современная статическая версия https://bodreevshow.ru/ на HTML/CSS/JavaScript. Материалы проверены 16 сентября 2026 года. Отдельный проект, не связанный с работающим сайтом.

## Как открыть

Откройте `index.html` двойным щелчком. Сборка, Node.js и сервер для просмотра не требуются. Изображения и библиотека Excel находятся в `assets`.

При необходимости локального сервера: `python3 -m http.server 8765`, затем http://localhost:8765/.

## Что внутри

- Главная: 10 зерновых наборов, Коробка № 1, FAQ, контакты, ссылки на видео и радио.
- `recipes.html`: 35 рецептов, поиск, фильтр новинок, чтение и скачивание рецепта.
- `digest.html`: 51 позиция оригинального дайджеста: 50 статей целиком и одна страница с объяснением недоступности оригинала.
- `articles/`: отдельные HTML-страницы статей.
- `merch.html`: три футболки по 1700 ₽ и таблица размеров.
- `random.html`: локальный Пивотрон, Excel/CSV, исключение участника, анонимные, цена билета, уникальные победители, локальная история.
- `content.json`: структурированное содержание для повторной генерации.
- `scripts/build.py`: пересоздание HTML из содержания (Python 3, без дополнительных зависимостей).

## Отличия от оригинала

Это тестовая версия, `noindex,nofollow,noarchive` стоят на каждой странице. Реальные формы WordPress, счётчики, реклама, Firebase и ключи оригинала не перенесены.

Кнопки заказа открывают окно подготовки письма; отправку пользователь подтверждает в своей почтовой программе. Сайт сам не отправляет заявки и не принимает оплату. Нужна настроенная почтовая программа.

Радио открывается на RadioBells; видео открываются по исходным ссылкам. Эти внешние ресурсы требуют интернета. Все остальные страницы, изображения, поиск и рецепты работают локально.

Пивотрон обрабатывает данные в браузере; история доступна только на этом устройстве и в этом браузере. Формат: «Имя пользователя», «Сумма, RUB», необязательная «Дата и время»; также поддерживаются «Имя» и «Сумма». Лимиты: 5 МБ, 10 млн билетов, история последних 100 победителей. Сумма каждой строки делится на цену билета с округлением вниз. Повторные строки одного участника дают дополнительные билеты, но в одном выборе он может выиграть только один раз.

Список недоступных исходных материалов и замен: [docs/source-notes.md](docs/source-notes.md). Карта исходных изображений: [assets/sources.json](assets/sources.json). Названия, цены и контакты перенесены как снимок на дату проверки; перед реальным запуском их нужно обновить.

## Проверка

```sh
python3 scripts/build.py
python3 scripts/check.py
node --check app.js
node --check raffle.js
node scripts/raffle.test.cjs
```

## Публикация на GitHub Pages

Публичный отдельный репозиторий `bodreevshow-redesign`. Загрузить файлы из корня проекта, затем Settings → Pages → Deploy from a branch → codex/redesign → / (root) → Save. Файл `.nojekyll` отключает обработку Jekyll. Относительные пути подходят для адреса вида `https://ACCOUNT.github.io/bodreevshow-redesign/`.

Материалы и фотографии принадлежат их правообладателям. Эта версия не означает передачу прав на оригинальные тексты и изображения. Библиотека SheetJS (XLSX) поставляется по Apache-2.0; источник: https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.16.9/xlsx.full.min.js (та же версия, которую использовал оригинальный Пивотрон).
